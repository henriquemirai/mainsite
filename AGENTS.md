## Development

This project uses Astro with Static Site Generation (SSG) and native CSS.

Use the following commands from the project root:

- `npm run dev`: Start the local development server.
- `npm run build`: Generate the static production build.
- `npm run preview`: Preview the production build locally.

Do not add dependencies or introduce new frameworks without explicit approval.

Follow the existing project structure, design system, and bilingual routing conventions.
